## Weekly Task Goals

The Weekly Task Goals feature allows users to enter their name, daily task goal, and number of weekly bonus tasks. The calculator multiplies the daily goal by five workdays and then adds the bonus tasks to determine the user's total weekly task goal.

## Magic Eight Ball

The Magic Eight Ball is an interactive feature that answers yes-or-no questions with a random response. Users enter a question and click the Magic Eight Ball to receive an answer.

### Technical Features

- JavaScript array containing multiple responses
- Random answer selection using Math.random()
- User input validation
- Event listeners for the Magic Eight Ball and reset button
- CSS animation when the Magic Eight Ball is clicked
- Reset button hides the current answer
